# 事实核查

`bg verify-sheet work` 生成 `work/verify/sheet.md`:每条待核命题及其引用的原文段落。

**最好由一个没有参与写作的子代理来做**:只给它 `sheet.md` 和本文件,不给它章节笔记和综合。自己核自己,容易用记忆替原文作证。

## 判定

对每一条,**只看给出的原文段落**,判断:

| verdict | 条件 |
|---|---|
| `ok` | 段落明确表达了这层意思;数字、主体、方向都对;`voice` 正确 |
| `partial` | 大体对,但有夸大、遗漏关键限定、数字不准,或锚点只覆盖了一半(另一半在别处) |
| `wrong` | 与原文矛盾:方向反了、主体错了、把作者反对的观点当成作者的、数字错 |
| `unsupported` | 给出的段落里找不到这层意思(可能锚点引错了,也可能是编的) |

特别留意:
- **立场归属**:`voice: author` 的命题,作者真的赞成吗?还是他转述后反驳的?
- **程度词**:"总是/大多/有时","证明/表明/提示"——不要把相关说成因果、把"可能"说成"一定"。
- **数字**:逐个对照。

## 输出

`work/verify/verdicts.json`:

```json
[
  {"id": "c3.2", "verdict": "ok"},
  {"id": "c4.5", "verdict": "partial", "reason": "原文说的是'大多',命题写成了'总是'", "fix": "改为'大多数'"}
]
```

非 `ok` 的条目必须有 `reason` 和建议的 `fix`。随后由主流程修改命题文字或锚点(或删除该命题);校验器会检查这些条目确实被改过。
