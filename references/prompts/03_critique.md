# 第 3 步:审读(哪些站得住,哪些要打折)

目的:让读者**知道该信多少**。一份只会复述的导读会让人高估一本书;审读要诚实地标出强弱。

## 铁律:区分两种来源
- `source: "book"` —— **书里自己说了**(作者承认样本小、自己修正了前面的说法、附录披露了数据来源的局限)或**可以直接从书里的内容推出**的缺口。必须有 `refs` 指向依据段落。
- `source: "outside"` —— **你的判断**(外部知识、常识、你注意到的替代解释)。不需要 refs,但会被页面用不同样式标注“外部判断·需自行核实”。**不要把外部知识伪装成书里的内容。** 对你不确定的外部事实,宁可不说。

## 输入
`bk digest -w work`;证据卡的 ev 字段已经记录了每条证据的类型/强度/局限。必要时 `bk find` 回原文。

## 格式 `work/critique.json`

```json
{
  "verdict": "总评:这本书在哪些方面可信、哪些方面要打折,以及读者应怎样使用它(3~5 句)",
  "strengths": ["站得住的部分,每条一句,说明为什么站得住"],
  "items": [
    {"id": "r1", "type": "evidence_weak", "severity": "high", "source": "book",
     "target": ["c02.k5"], "refs": ["c10:1"],
     "text": "指出问题的完整句子,说明依据"}
  ]
}
```
type:evidence_weak 证据偏弱 / gap 论证缺口 / alt_explanation 替代解释 / overreach 结论过强 / scope 适用边界 / inconsistency 前后不一致 / counterexample 反例 / strength 站得住的部分。
severity:high 动摇核心结论;med 削弱某个支柱;low 细节。

## 该找什么
1. **证据账本**:逐条看 evidence 卡——样本、方法、是否相关≠因果、作者自己的保留。重点看**支撑 tier 1 论断的证据**是否撑得住。
2. **论证缺口**:从证据到结论,中间有没有跳步?支柱靠什么撑着?哪些 tier 1 论断**只有作者的断言,没有证据**?
3. **替代解释**:同样的数据还能怎么解释?(书里已提到的写 source=book,你想到的写 outside)
4. **过强/泛化**:经验法则被写成定律?单一行业的结论推到所有组织?
5. **前后不一致**:某处的说法与另一处冲突,或被后面修正。
6. **适用边界**:书里划了边界吗?没划的,哪些情形可能不适用(outside)?

至少 3 条 items,其中要有 strength 类的肯定项;不要为了显得“批判”而硬挑。所有 `target` 必须是真实存在的卡片 id。

## 完成标准
`bk check --full` 里 critique 相关错误为 0;source=book 的条目都有 refs;outside 的条目措辞克制(“可能”“值得核实”)。
