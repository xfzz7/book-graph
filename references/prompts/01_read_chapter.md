# 第 1 步:读一章,写章笔记

你的任务不是“缩写这一章”,而是**把这一章的论证搭起来**:它在全书里承担什么任务、有哪些承重的论断、靠什么证据、作者自己承认了什么局限。

## 流程(每章都这样)

1. `bk brief cXX -w work` —— 全书定向 + 前面各章要点 + 已有术语 + 下一个可用 id。**别的上下文都可以丢,这份简报不能不看。**
2. `bk read cXX 1 -w work`(章长会分成多块:`bk read cXX 2` …)。读的时候先回答三个问题:
   - 这一章在全书论证里承担什么任务?
   - 本章的主论点是哪一句?(它会是本章的“顶层卡”,parent 为 null)
   - 作者靠什么撑住它:理由、机制、证据、案例?作者自己承认了哪些局限、做了哪些修正?
3. 写 `work/notes/cXX.json`。章很长、分了多块时,每读完一块就写一份 `cXX.json`、`cXX.2.json` …(卡片 id 接着编号;`meta` 只在其中一份里写一次)。
4. `bk check cXX -w work` —— 按提示修,**最多循环 3 轮**。能修的错不要用 waive 绕过去。
5. 进入下一章,重新 `bk brief`。

## 文件格式(完整字段说明见 references/schema.md)

```json
{
  "chapter": "c04",
  "meta": {
    "role": "本章在全书论证里的任务(1~2 句)",
    "summary": "本章讲了什么(3~5 句,按作者的推进顺序)",
    "takeaway": "读完只记一句话",
    "priority": "must | normal | skim",
    "reading_questions": ["读本章之前带着的 1~3 个问题;本章必须能回答它们"]
  },
  "cards": [
    {"id": "c04.k1", "text": "……", "label": "≤14字", "kind": "claim", "voice": "author", "tier": 1,
     "parent": null, "rel": null, "refs": ["c04:2"], "anchor": "原文里的一小段(逐字)"}
  ],
  "concepts": [
    {"term": "回声成本", "def": "……", "origin": "coined", "refs": ["c05:1"], "anchor": "回声成本", "not": "与……的区别(可选)"}
  ],
  "links": [
    {"from": "c05.k4", "to": "c04.k2", "type": "causes", "note": "为什么有这条关系"}
  ]
}
```

## 一张卡片 = 一个“承重的点”

### 选什么(最重要的判断)

**没有数量配额。** 只写“拿掉它,读者对论证的理解会出洞”的东西:
- 本章主论点,以及撑起它的理由/机制;
- 本章用来支撑论点的关键证据(数据、研究、调研)和关键案例;
- 作者定义的概念、划出的区分;
- 作者回应的反对意见;
- **作者对自己的限定、修正、承认的局限**(最容易被摘要吞掉,也最值钱);
- 可以照着做的方法,以及它的适用条件。

不要写:修辞、过渡、重复、纯氛围的故事细节。题外话如果长得像论据(读者可能误当成证据),写一张 `aside` 卡并 tier 3,提醒“这不是论据”。
自检用的量级:每千字 0.3~3 张卡。明显更多是在逐句改写,明显更少是漏读。

### tier(承重程度)
- **1**:拿掉它,本章/全书论证就垮了。每章通常 1~3 张,不超过卡片总数的 40%。
- **2**:重要的支撑(关键证据、关键机制、关键限定)。
- **3**:细节、例子、次要说明。总览默认不显示 tier 3,读者想看再展开。

### kind(是什么)
claim 论断 · mechanism 机制(为什么/怎么起作用) · method 方法(可照做) · evidence 证据(数据/研究/调研) · example 案例/故事 · objection 书中提到的反对意见 · caveat 限定/边界/自我修正/承认的局限 · aside 题外话。

### voice(谁在说)——这是最常出错的地方
- `author`:作者自己主张的。
- `other`:作者转述的**别人**的观点、被批评的流行看法、引用的专家、案例里人物的话。**作者在批评的观点,绝不能写成 author。**
- `hedged`:作者明确存疑的(“可能”“我猜测”“尚无定论”)。

### text(怎么写)
- 一个**自足的完整句子**:脱离上下文也读得懂(把“这”“该方法”换成具体名词);只说一件事。
- **转述,不照抄**:与原文连续相同的字符达到 16 个汉字(或约 8 个英文词)会被校验拦下。
- **保留作者的限定语**:“大致”“在我看来”“经验法则”“没有做过统计检验”。把“可能”写成“是”,就是失真。
- 数字、名称原样保留;**不要补书里没有的数字、因果或背景**。你自己的判断不进卡片(去 critique)。
- 不要写“本章讲了……”“作者认为……”这类元话语——卡片本身就是作者的论断,立场由 voice 标注。

### parent / rel(它挂在谁下面)——搭论证树
每张卡要么是**顶层卡**(parent=null,通常是本章主论点,每章 1~3 张),要么挂在一张卡下面:

| rel | 含义 | 例 |
|---|---|---|
| supports | 是 parent 的理由/证据 | 调研结果 → “满载使延误波动变大” |
| explains | 是 parent 的机制 | 到达与处理的波动叠加 → “接近满载时等待急剧上升” |
| illustrates | 是 parent 的例子 | 急诊科案例 → 上面那条论断 |
| elaborates | 是 parent 的细化/组成部分 | 三步法的第一步 → 三步法 |
| qualifies | 给 parent 加条件/边界 | “需求稳定时不适用” → 三步法 |
| objects | 是针对 parent 的反对意见 | |
| rebuts | 是对某个反对意见的回应(parent 是那条 objection) | |
| revises | 修改/收回 parent 的说法(**可以跨章**:parent 填前面某章的卡) | 第七章的“临界线随波动而变” → 第三章的“85% 线” |

parent 可以指向前面其他章的卡。**后面章节对前面说法的修正/限定/补充,务必用 parent 挂过去**——这是读者最容易漏掉的“书的自我修正”。
附录、注释里披露的方法细节,同样用 `qualifies`/`supports` 挂到被它说明的那张卡上。

### refs 与 anchor(把每张卡钉在原文上)
- `refs`:这张卡依据的**段落 id**(`bk read` 输出里方括号里的,如 `c04:2`),通常 1~2 个,最多 6 个。必须是本章的段落。
- `anchor`:从被引用段落里**逐字**摘一小段(汉字 6~20 个 / 英文 3~8 个词),读者可以在电子书里 Ctrl+F 搜到。要连续、不跨标点和换行、尽量有辨识度(别选“因此”“我们认为”)。校验会逐字核对;找不到就是你写错了或编造了。

### ev(证据卡必填)
`kind` 为 evidence/example 且 tier 为 1~2 时,写 `"ev": {"type": "data|study|case|anecdote|theory|analogy|authority", "strength": "strong|moderate|weak|illustrative|unclear", "limit": "这条证据能支持到哪一步、有什么局限"}`。
- **strength 只按书里交代的方法和作者自己的话来评**(样本多大?怎么得到的?作者自己承认了什么?)。你对该研究的外部了解不要写在这里,留到第 3 步 critique 里并标为外部判断。
- illustrative = 只是用来说明、不构成证明的例子/故事。书里没交代方法就写 unclear,limit 写“书中未交代”。

## 概念(concepts)
只收**作者自造、或赋予特殊含义**的词(origin 为 coined/redefined),以及作者专门区分的一组近义词(borrowed)。`term` 必须是书里的原词;`def` 用你的话;`not` 写“它不是什么/和哪个词易混”。普通名词不要收。

## 关系(links)
大部分关系已经由 parent 表达了。`links` 只补 parent 表达不了的:
`causes`(因果链上的一环,用来拼回路)、`depends_on`、`tension`(书中前后不一致或相互拉扯)、`restates`(重述)、`applies`(把前面的原则用到新场景)、`revises`。每条必须写 note(为什么)。
`to` 指向**已经写好的卡**(前面章节的卡可以);后面章节才出现的关联,留到综合阶段补。

## 提交前自检(写完先过一遍再跑 bk check)
- [ ] 本章主论点有没有成为顶层卡?有没有 tier 1?
- [ ] 作者转述/批评的观点,voice 是 other 吗?
- [ ] 作者的限定语、自我修正、承认的局限,写进去了吗(caveat / revises / ev.limit)?
- [ ] 每个数字都来自被引用的段落?
- [ ] 有没有把题外话当成论据?
- [ ] anchor 是不是真的从原文逐字摘的?
