# 评测说明

目的:用实际运行回答“新版是不是真的比旧版更能帮人读懂一本书”,而不是凭感觉。

## 材料
- `canary/book.md`:虚构的中文非虚构小册子《缓冲的逻辑》(约 7.6k 汉字)。**刻意埋了陷阱**:被批评的流行观点(满载崇拜)、作者的自我修正(85% 线→随波动而变)、弱证据(14 家自愿公司,附录披露 3 家为自我报告)、经验法则被当作定律的风险、题外话、限定条件。因为内容是新编的,任何“书里没有”的内容都是编造,可以被识别。
- `canary/quiz.json`:38 道理解题(含 gold 与评分要点),覆盖定义/立场/证据/修正/边界/结构/应用,以及 3 道“书里没有”的探针题。
- `canary_en/book.md`:虚构的英文短册,用来测“英文书 + 中文输出”的跨语种路径。
- `results/canary_zh/`:本次运行的原始产物与评分(旧版 book.json、新版笔记/综合/审读/自测题/核对日志、答卷与评分、忠实度核查)。

## 协议(都是盲测,执行者/答题者/阅卷者互不知情)
1. **执行**:一个只拿到 SKILL.md 的子代理,像第一次使用的人一样,分别用旧版和新版把同一份 epub 做成交付物。执行者不得读取评测材料。
2. **全量问答**:答题者只能读交付物(旧:两个 HTML;新:HTML+Markdown+TSV),不读原书,回答 38 题;找不到就写“材料中没有”。阅卷者按 rubric 0/1/2 打分。
3. **默认视图问答**:只给读者“不点开细节时看到的”那一层(旧:总览导图的篇/章/要点文字;新:一页读懂+章节导读),同样答题评分。衡量“分层”的价值。
4. **忠实度核查**:从旧版命题、新版卡片各随机抽 40 条,混在一起打乱,由不知来源的核查者对照全书判断(忠实/说过头/走样/找不到/归因错误/太空泛)。
5. **缺陷注入**:往两版各自“合格”的产物里注入 5 类缺陷(改数字、编造、整句照抄、引错段落/方向反转、说过头、立场错标…),看校验能否发现。旧版见 `old_blindspots.py`,新版见 `mutation_new.py`。
6. **种子故障**:独立核对时批次里混入故意写坏的条目,衡量核对者是否认真(`audit/seed_result.json`)。

复现:`python canary/blind_quiz.py out.json` 生成不含答案的题目;`python canary/score.py grades.json` 汇总分数。
评测本身的局限见 REPORT.md。
